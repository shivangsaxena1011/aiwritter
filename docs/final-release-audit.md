## 4. Architectural & Implementation Inventory

### 4.1 Authoritative Production Components
1. **Pipeline Orchestrator:** `BookGenerationOrchestrator` (`backend/app/workers/pipeline.py`) — Manages the 14-stage workflow from syllabus intake to final independent artifact audit.
2. **Subject Knowledge Architecture:**
   - Provider Registry: `backend/app/agents/subject_knowledge_base.py` defining `PhysicsKnowledgeProvider`, `MathematicsKnowledgeProvider`, `ComputerScienceKnowledgeProvider`, `ElectronicsKnowledgeProvider`, `MechanicalEngineeringKnowledgeProvider`, and `GenericAcademicKnowledgeProvider`.
   - Dispatch Model: `backend/app/agents/subject_knowledge_model.py` which dynamically dispatches syllabus topics to their respective domain provider.
3. **Pedagogical Table & Diagram Planners:**
   - `TablePlanner` (`backend/app/agents/table_planner.py`): Content-aware table necessity evaluator with cryptographic markdown hashing to eliminate duplicate tables.
   - `DiagramPlannerAgent` & `DiagramGeneratorAgent` (`backend/app/agents/diagram_system.py`): Pedagogical figure planning with Matplotlib / SVG generation and fallback figure boxes.
4. **Assembly & Document Engine:**
   - `BookAssemblyModel` (`backend/app/services/document/book_assembly_model.py`): Strongly-typed dataclass model capturing full document hierarchy, metadata, section purpose, and count manifests.
   - `DOCXExporter` (`backend/app/services/document/docx_engine.py`): Deterministic renderer translating `BookAssemblyModel` into OpenXML Word documents with Times New Roman 12pt, 1.5 line spacing, native `<m:oMath>` equations, formatted tables, and centered figures.
5. **Independent Artifact Auditor:**
   - `IndependentArtifactAuditor` (`backend/app/services/document/independent_artifact_auditor.py`): Authoritative auditor that re-opens the compiled DOCX from disk, verifies paragraph/heading/table/figure/math counts against `planned_manifest` and `BookAssemblyModel`, audits TOC integrity, verifies caption relevance, and flags blocking publication defects.

### 4.2 Deprecated / Superceded Modules (Retained for Backwards Compatibility)
- `backend/app/agents/content_writer.py` — Predecessor to `content_writer_agent.py`.
- `backend/app/agents/repetition_detection_agent.py` — Basic n-gram checker, superseded by `repetition_detector_2.py`.
- `backend/app/agents/diagram_prompt_agent.py` — Early prompt builder, superseded by `diagram_system.py`.

## 5. Security & Configuration Review

1. **Client-Side Secrets Protection:**
   - Previous frontend implementations accepted API keys in web forms. In production, `GEMINI_API_KEY` must be configured exclusively server-side via `.env` or system environment variables. Client requests must never leak credentials or bypass server authentication.
2. **Mock Provider Guard:**
   - In `backend/app/core/config.py`, add `ALLOW_MOCK_PROVIDERS: bool = False` (default False in production).
   - In `backend/app/main.py`, lifespan must verify: if `APP_ENV == "production"` and `AI_MODE == "mock"`, raise `RuntimeError("Mock AI provider is strictly prohibited in production mode. Configure GEMINI_API_KEY or set APP_ENV=development.")`.
3. **Database Security & Configuration:**
   - In development/local mode: SQLite with WAL mode and `busy_timeout=30000`.
   - In production mode: PostgreSQL connection string via `DATABASE_URL`.
   - Secret Key: Warn or fail if default `SECRET_KEY` is detected in `APP_ENV=production`.
